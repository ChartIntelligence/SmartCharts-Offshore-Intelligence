# Governed Scalar Field Runtime v1

Contract: `pelora-scalar-field-runtime-v1`. Adapter: `pelora-scalar-field-runtime-adapter-v1`.

## Authority and coexistence

Task 11B adds an explicit `mode=scalar` branch to GET `/api/ocean/field`.
Existing currents and bathymetry retain `pelora-spatial-field-v1`, their registry,
latest-available selection, acquisition, cache, status and response behavior.
The existing frontend consumes those two shapes; no frontend consumer or rendering
is added. The scalar envelope contains the unchanged governed scalar delivery,
rather than translating away its provenance into the legacy spatial contract.

Default servers return `SCALAR_RUNTIME_DISABLED` for scalar requests. Only explicit
server-construction dependency injection enables the synthetic runtime. There is
an own data-property function requirement: inherited properties, accessors and
truthy nonfunctions cannot enable it. Unknown, blank or duplicate `mode` values
return an explicit invalid-field-mode error; absent mode retains legacy dispatch.
There is
no environment switch, production fixture registration, live provider or latest
selector. The fixture lives under backend tests and is never imported by runtime.

The test constructs a validated synthetic Ocean Product Frame, writes it through
the archive writer with a simulated atomic/durable in-memory port, pins the exact
receipt, then invokes scalar delivery through its exact archive reader. This test
double does not establish production durability. All responses identify their
scope as `SYNTHETIC TEST EVIDENCE`; successful fields require a synthetic provider
and synthetic product and dataset identifiers. Those labels are not scientific qualification.

## Request and source binding

Exactly these query fields are required, once each:

`mode=scalar&layer=synthetic-sst&evidence=synthetic-day-v1&component=temperature&bbox=-90,25,-86,27&strideX=1&strideY=1`

The server configuration maps the opaque test selector to an exact archive ID,
receipt digest and component. Unknown query keys, duplicate keys, arbitrary
archive locators, private fields, values and latest-product names are rejected.
There is no filesystem, SQL, provider URL or credential input. Configuration is
snapshotted; time is supplied explicitly and never generated by a clock.

Bounds are decimal geographic coordinates, ordered west/south/east/north,
finite and within the locked delivery contract's geographic limits. Antimeridian
crossing and silent wrapping are unsupported. Strides are positive safe integers.
Selection remains inclusive and source-index anchored:
`west <= x[i] <= east && i % stride.x == 0`, likewise for y; offset is
`j * sourceWidth + i`. No interpolation, endpoint appending, unit conversion,
scientific coercion or rounding occurs.

## Response and budgets

The envelope has contractVersion, adapterVersion, synthetic, evidenceNotice,
status, reason and field. A successful field retains its delivery ID, exact archive,
receipt/frame/content digests, product, component/unit, evidence class, temporal
support, requested/delivered bounds, axes, dimensions, native/source-delivered/
delivery resolutions, values, missing reasons, companion references and lineage.
Zero stays zero; land and provider-no-data remain distinct null cells. A valid
field with missing cells is `DELIVERED_PARTIAL`, not failure.

All budgets are explicitly injected TEST configuration, not production policy:

- maxSourceBytes bounds normalized frame JSON inspected after the port returns.
- maxSourceCells bounds each source component's cell count before delivery.
- maxCells bounds delivered cells through the scalar contract.
- maxPayloadBytes bounds canonical scalar-field JSON through that contract.
- maxHttpBytes bounds UTF-8 serialized response-body JSON, including the envelope.

Source guards do not bound archive-port I/O, allocation before return, receipt size,
network transfer or browser/GPU memory. A future storage port must independently
bound reads and allocations. HTTP-body limits exclude protocol headers and transport
overhead. No full-region production delivery or mobile budget is selected.

## Failures and cancellation

Invalid requests, bounds, components, layers and selectors return 400. Disabled
runtime and archive-not-found return 404; unavailable storage 503; archive integrity
failure 502. No selected cells or unsupported grid return 422. Source-processing,
delivered-cell, canonical-field-byte and HTTP-body limits return 413, with distinct
status/reason. Transformation failure returns 500. Cancellation returns an internal
499 result; disconnected HTTP clients receive no response. Exceptions are sanitized.
Failures have null field, never fabricated temperatures or empty successful grids.

Cancellation is checked by scalar delivery before and after the archive read.
Request abort/response close signals cancellation and listeners are removed afterward.
This does not cancel an in-flight archive operation or preempt synchronous processing.

## Identity, caching and future consumers

No scalar cache is introduced. Repeated identical requests reproduce the derivative
identity. Any future immutable derivative cache must key by delivery ID. Mutable
latest-qualified selection remains separate from immutable archive evidence and
derivative caching. A later revision cannot silently replace a pinned receipt.

The asymmetric 3-by-2 synthetic ANALYSIS Kelvin fixture has zero, finite values,
provider-no-data and land cells; fixed interval support; explicit resolutions;
and synthetic provenance/lineage. It makes no claim about actual ocean conditions.
Aligned quality/uncertainty remains provider evidence, never Pelora confidence.

The boundary is environmental and species-neutral. It accepts no captain, catch,
Fishing Log, Auth, score or rank fields. Viewports are request geometry, not private
report evidence. Generic upstream strings still require governed provenance review;
schema validation is not a sensitive-data detector. Payloads are not logged.

Deferred: qualified live products, production archive storage and retention,
production budgets, freshness/latest selection, frontend parser and scalar shading,
publication, historical association and learning. No Task 11A styling, locked
scientific contract, current/bathymetry science or Task 9E-D state is changed.

## Adversarial review

Regressions demonstrated and corrected three gaps: inherited dependency activation,
ambiguous unknown-mode fallthrough, and acceptance of a real dataset ID beneath a
synthetic provider/product label. No scientific contract amendment was needed.
The trusted injection boundary still owns the supplied runtime implementation and
the truthfulness of generic upstream strings; this is not a sandbox or a detector
of falsified provenance. No response declares product qualification or freshness.

Offline tests invoke actual HTTP handlers without opening sockets. Legacy success
tests replace fetch with an in-memory response function that never delegates to a
transport. Legacy cancellation has not been expanded; the new abort handling applies
only to the scalar branch. Synthetic inputs and outputs remain test-only, and HTTP
byte limits are response-body limits rather than network-transfer limits.
