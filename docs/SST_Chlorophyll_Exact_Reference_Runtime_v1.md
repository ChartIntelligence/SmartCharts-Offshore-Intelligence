### Options, capture semantics and consumer boundaries

Capture v2 requires a **string enum**, not availability=true/false. Available
requires finite C/F. Unavailable, no-valid-pixel, provider-unavailable and
request-failed can retain finite diagnostic values; capture is not an automatic
iff classifier. Missing, Boolean, null, unknown, stale, degraded and invalid
availability values are rejected. Explicit unavailable does not encode a cause
or establish eligibility. The selected adapter deliberately uses only the two
existing center numeric-state outcomes and leaves failure diagnostics separate.

Directional SST writes available/unavailable itself after the same paired-value
normalization; settled request failures write request-failed. Center and
directional acquisition/source shapes remain distinct. Merely copying the
directional inference would not be authority; the independently emitted center
Boolean is what supports the bounded mapping.

A producer amendment could expose the existing pair-admission decision earlier,
but is **not required for the bounded present-state adapter**. It would be
EXPOSE_EXISTING_GOVERNED_STATE only with the narrow numeric meaning above, not a
new scientific availability class. It would change observable source shape and
needs separate approval plus snapshot/publication/history compatibility tests.
No field is proposed for automatic addition in this review.

A capture successor is **not demonstrated necessary for admitted center states**:
v2 can express both outcomes. If complete capture of the failure-fallback branch
is later required, explicit producer-state exposure or another separately reviewed
contract is needed. `AVAILABILITY_UNKNOWN_NOT_AUTHORIZED`: omission is a fact of
the current shape/fallback, not an existing governed unknown enum. Do not encode
absence as false, unavailable or unknown.

Center evidence, quality, status and immediate downstream scoring currently use
the value/derived group predicates, not center source availability. Directional
feature admission and negative-adequacy checks read availability on **samples**;
they must not be redirected to the new center annotation. The generic current-age
helper has a source-availability check but is a current-cache caller, not a center
SST consumer. Capture validation/replay retain source availability; no existing
live scalar replay integration is qualified. Snapshot builders, HTTP publication,
browser row storage and backend adaptation observe/copy entire objects. The
semantic surface registry treats source availability as scientific evidence, so
an additive producer field is not an invisible metadata change. Historical
comparison, persistence and selector behavior must stay untouched.

Adapter implementation tests must cover Boolean presence/type/version and exact
center binding, all matrix rows, spatial failure without a Boolean, contradictory
pairs, input mutation, canonical round trip, original source absence, processing
lineage, same-time changed content, signed C/F zero, and no changes to consumer
outputs. Neither adapter readiness nor a future capture grants receipt authority.
