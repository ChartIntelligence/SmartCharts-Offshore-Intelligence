# Pelora release flag image assets

Seven individually cropped PNG files extracted from the latest founder-approved visual sheet. The fish silhouettes and pennant artwork are preserved; labels below the pennants are excluded.

These are raster PNG crops on white backgrounds, **not vector SVGs**, not transparent PNGs, and not yet optimized for small UI display. They are visual design assets for Claude to integrate or use as approved reference. The white marlin pennant itself is white and must remain legible against the UI.

Species: blue_marlin, white_marlin, sailfish, yellowfin_tuna, blackfin_tuna, mahi_mahi, wahoo.

Only show a release flag for an actually recorded release, not a raised/missed/landed fish. Preserve private reports and historical fields.
